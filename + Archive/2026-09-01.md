### Definisi
- Data => Object atau kejadian yang bisa diamati, kumpulan nilai mentah
- Informasi => Data yang sudah di proses/dapat di simpulkan
- Pengetahuan => informasi yang di proses sehingga kita dapat acuan baru/rekomendasi tindakan
- Kebijaksanaan => kemampuan untuk memahami dan menggunakan pengetahuna untuk mengambil keputusan

#### Contoh:
- data : nilai mahasiswa
- informasi : berapa mahasiswa yg nilainya < 50
- pengetahuan : mahasiswa dengan nilai dibawah < 50 kesulitan memahami materi
- wisdom : dosen mengguanakan metode pendampingan kepada mahasiswa dengan nilai < 50

### Perinsip pemodelan pengetahuan 
- entity => object dari suatu konsep
- attribute => karakteristik yang mendefinisikan object
- Relation => hubungan antara dua atau lebih konsep
- constraint => batasan formal terhadap interpretasi konsep atau relation
- taxonomy => hierarki generalisasi/spesialisasi antara konsep
